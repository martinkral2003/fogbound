# FOGBOUND: DOMINION — contract for the RTS mode (src/rts/)

A dark-fantasy real-time strategy game, evolved from the warlord mode: **Stronghold-style walls and sieges** + **Age of Empires-style economy/army control** + **Original War-style named characters (up to 3 generals who level up)** + **dark magic**. 4 lords (Necromancers, Orcs, Demons, Cult) on the existing island (src/world.js: hills, roads, hill forts, temple), single player vs 1-3 AI lords first (prototype), sim kept deterministic so multiplayer is possible later.
The old warlord mode (src/sim.js, ai.js, render.js, ui.js, controls.js, main.js, data.js) and the Hero mode (src/rpg/) MUST keep working: never edit them except tiny additive edits to index.html / src/main.js for the mode menu (client-controls agent owns that). RTS code only READS src/world.js, src/data.js (WORLD, BIOME, MONSTERS, CAMP_TABLE), src/models.js, src/worldview.js, src/util.js.

## Pillars
1. **Command from above**: free RTS camera, box selection, control groups, orders (move/attack-move/patrol/hold/guard/gather/build/repair/garrison/cast), command card, minimap.
2. **Army up to 50 military units per lord** (workers separate, up to 24) + **up to 3 Generals** (named heroes, level 1-10, skills, gear slot, revive at the Keep). Every unit levels up (veterancy 1-6) and unit types have 2 upgrade lines.
3. **Walls matter** (Stronghold): wall segments, corner/gate towers, stairs, **units can walk on wall-tops** (wall-walk layer), archers/cannons on walls, gates, moats/palisades/spikes, wall upgrades (timber -> stone -> black stone). **Siege**: rams, catapults, ballistae/cannon, siege towers, sappers; breaching, burning.
4. **Dark economy**: 5 resources — **Tithe (gold), Rotwood (timber), Black Stone (stone), Blood (food), Souls**. Workers gather and carry to storage buildings. Souls come from deaths (all sides), soul wells and sacrifice; they pay for magic, elite units and wonders. Upkeep: Blood feeds units; starvation causes desertion.
5. **Magic**: each faction has a school (Necromancy / War-Magic (orcs) / Infernal (demons) / Blood-Cult), mana from Sanctums and ley-line sites, spells cast by Generals, caster units and magic towers, researched in a spell tree.
6. **A rich map**: neutral villages, ruins with relics, graveyards, blood altars, ley lines, wildlife, bridges/fords, weather, day/night that matters, roaming monsters, events (Dread Moon, plague, storm), plus concepts of our choosing.

## State (st) — see core.js
st = {mode:'rts', seed, world (generateWorld), rng (mulberry32; use st.rng NOT Math.random in sim code), t, tick, nextId, teams[], ents[] (units; kind 'unit'), blds[] (all buildings incl. wall pieces), nodes[] (resource nodes), projs[], zones[], events[], byId (Map id->ent|bld|node), nav (owned by walls lane), neutral[] (neutral structures: villages, relics, altars...), weather, over}.
**team** = {id, faction, human, name, res{gold,timber,stone,blood,souls}, cap{mil, work, gen}, pop{mil,work}, popMax (houses raise it), mana, manaMax, manaRegen, generals[unit ids], tech{id:true}, up{upgradeId:level}, spells{id:true}, alive, ai (object or null), stats{kills,lost,gathered{...}}, fog (optional)}.
**unit** (Units.spawn) = {id, kind:'unit', type, role:'worker'|'melee'|'ranged'|'cavalry'|'heavy'|'siege'|'caster'|'flyer'|'general'|'beast', team, x,z,y, r (radius), face, hp,maxHp, armor, atk{dmg,range,cd,dtype,splash?}, speed, vision, lvl, xp, vet (1-6), orders[] (queue; orders[0] active), order = orders[0], stance 'aggressive'|'defensive'|'hold', layer:'ground'|'wall' (wall-walk), garrison (building id or 0), carry{res,amt}, abilities[{id,cd}], buffs[], stun, burnUntil..., alive}. Generals add {general:true, name, gold-gear slots, skills{}, points, deathT}.
**building** (Buildings.create) = {id, kind:'bld', type, team, x,z,rot,w,d,h, hp,maxHp, state:'building'|'ready'|'upgrading'|'burning'|'ruin', progress 0-1, buildT, queue[{unit|tech|spell, t, total}], rally{x,z}, garrison[], range, atk, wall:{piece:'wall'|'tower'|'gate'|'corner'|'stairs'|'palisade'|..., walkable:true (units can walk on top), height, tier}, ...}. Wall pieces are buildings with `wall` set.
**node** (Econ) = {id, kind:'node', rtype:'tree'|'mine'|'quarry'|'bloodwell'|'soulwell'|'farm'|'herd'|'graveyard', res, amount, x,z, r, ...}.
**order** objects: {type:'move',x,z} {type:'attack',target} {type:'amove',x,z} {type:'patrol',x,z,x0,z0} {type:'hold'} {type:'guard',target} {type:'gather',node} {type:'build',bld} {type:'repair',bld} {type:'garrison',bld} {type:'cast',spell,x,z,target} {type:'ability',id,x,z,target} {type:'return'}.

## Commands (client/AI -> sim): inputs[teamId] = {cmds:[...]} passed to step(st, dt, inputs)
Each module exports `command(st, teamId, cmd) -> true if handled` and core dispatches to all modules until one returns true. Command shapes:
{t:'order', ids:[unitIds], order:{...}, queue:boolean} {t:'train', bld, unit, n} {t:'cancelTrain', bld, idx} {t:'build', type, x,z,rot, workers:[ids]} {t:'buildline', pieces:[{type,x,z,rot}], workers:[ids]} {t:'demolish', id} {t:'repair', ids, bld} {t:'research', bld, tech} {t:'upgrade', bld, upgrade (unit upgrade lines)} {t:'rally', bld, x,z} {t:'garrison', ids, bld} {t:'ungarrison', bld, ids?} {t:'cast', caster (unit or bld id), spell, x,z, target} {t:'ability', ids, id, x,z, target} {t:'trade', give, get, amount} {t:'sacrifice', ids} {t:'setStance', ids, stance} {t:'general', op:'skill'|'revive'|'equip', ...}.

## Step order (core.step)
cmds -> AI.update (produces cmds for AI teams) -> Buildings.update (construction, production queues, burning) -> Econ.update (gather/carry/upkeep/income/trade) -> Units.update (orders, movement via Nav, auto-acquire, formation spacing) -> Combat.update (attacks, projectiles, abilities, status, leveling) -> Walls.update (wall-walk, gates, wall defences) -> Siege.update (siege weapons vs structures, fire) -> Magic.update (mana, spells, towers) -> WorldX.update (events, wildlife, weather, villages) -> core cleanup (deaths, souls from deaths, elimination/victory).
killEnt/killBld in core are the ONLY way to kill (they award souls/xp/hooks).
