Read CLAUDE.md "Design v0.4" first (the agreed design). `src/V3.md` still documents the kept modules (map, perks, aiming, dungeons, POIs, travel, plates, loot).
Premise: you are a human hero; orc hordes are crushing humanity; no base, no building, no research, no region ownership, no lord factions.

## Teams and world model
- `st.teams[0..3]` = the four HEROES (team id = hero id). Team 0 = the human (or `auto=1` AI). Teams 1-3 = AI rival heroes. Fields kept: `hero, gold, sk, perks, cd, alive, human, respT, income:0`. New: `team.bg` ('soldier'|'hunter'|'mage'|'outlaw'), `team.orbs`, `team.quests`, `team.followers` (entity ids, max 4), `team.lastWs` (last used waystone id, respawn point), `team.score`.
- Team ids on entities: -1 = hostile neutrals (wild monsters AND orcs; they do not fight each other), 0-3 heroes (hostile to each other: PvP/ambush allowed, but heroes do not attack town guards), 4 = HUMANITY (town guards, villagers, merchants; not hostile to heroes 0-3, hostile to team -1). `st.teams[4]` is a stub `{id:4, alive:true, human:false, ai:false, hero:null, gold:0, humanity:true, f:{...}}` so loops that index `st.teams[e.team]` do not crash. CORE lane implements this and updates `hostile()` in sim.js.
- Win/lose: `st.over = {winner, reason}`; reasons `'warlord'` (Orc Warlord killed; winner = team with most score among the heroes that took part, human gets the victory screen if it has the most or if cooperative victory = everyone wins humanity; keep simple: the killer's team wins, everyone sees "Humanity is saved"), `'capital'` (capital fell and was not reclaimed in time: defeat for all), `'dead'` (human hero permanently out: not used in v0.4 slice). Use `endGame(st, winner, reason)` exported by CORE from sim.js.
- Items: gear slots `weapon, helmet, armor, amulet` (kept). New item kind `{kind:'book', skill:id, name, rarity}` (skill book: teaches skill id when used; ECON lane). Quick-use consumables `potion`, `scroll` exist or are added by ECON.

## Shared state added by v0.4 (single source of truth; JSON-able)
- `world.sites` (MAP lane, replaces regions/keeps): `{towns:[{id,name,x,z,r,kind:'village'|'town'|'capital',wsId,start?:bool}], capital: townId, startTown: townId (the first village, NW-ish near the human spawn), orc:{camps:[{id,x,z,tier,kind:'camp'|'fort'|'warcamp'}], warcamp:{x,z}, warlord:{x,z}, lands:[x0,z0,x1,z1] or polygon}, frontPath:[[x,z],...] (from orc lands toward the capital, passing near towns in order), lairs, dungeons, pois, waystones:[{id,x,z,townId?}]}`. Content is deliberately ASYMMETRIC (orc lands NE, capital SW, human towns/villages spread, start village near the spawn). `heroSpawns:[{x,z}x4]` four distinct starting spots near the start village (rivals spread a little).
- `st.towns[]` (TOWNS lane): site fields + `{state:'safe'|'besieged'|'fallen', def:0..1, pop, services:{shop,trainer,board}, stock:[items], quests:[...], fallT, saved:0}`; helper exports `townAt(st,x,z)`, `isSafeZone(st,x,z)`.
- `st.horde` (HORDE lane): `{path, dist (current front distance along frontPath), speed, camps:[{id,x,z,tier,hp,alive}], assaults:[{id,townId,state,ids:[monsterIds]}], warlord:{id, state:'idle'|'fight'|'dead'}, capital:{state:'pending'|'siege'|'fallen'|'held', t}}`. Exports `frontPos(st)`, `activeAssaults(st)`, `hordeList(st)` for UI/map.
- `team.quests` (TOWNS lane): `{active:[{id,kind,townId,desc,need,prog,reward:{gold,xp,orbs,item}}], done:n}`.
- Followers (RECRUITS lane): entities `kind:'unit'`, `recruit:true`, `team:<hero team>`, `owner`; `team.followers`; stances via existing cmds `follow/hold/amove`.
- ECON lane: `team.orbs`, `st.drops` death-gold piles `{id,x,z,gold,team,t}`.

## ECON lane v4 API (orbs.js, loot.js, perks.js, data.js ECON4/ORB/BOOK/POTION_DROP blocks, tools/v4-econ-test.js)
Tuning lives in data.js: `ECON4` (stipend, kill/chest gold multipliers, death drop share 0.3, pile life 300 s, bag size), `ORB` (costs, rank bonuses, drop chances, dungeon/POI orbs), `BOOK` (prices, drop chances), `POTION_DROP`.
- **Orbs**: `team.orbs`, `team.orbsTotal`. `orbs.give(st, teamId, n, why, x?, z?)` / `orbs.spend(st, teamId, n, why)` / `orbs.orbsOf`. Event `{type:'orbs', team, amt (negative when spent), why, x, z}` (UI/HORDE show pickups). Automatic sources (onKill): bosses (2-4 by tier; Warlord 6 if the entity has `warlord:true` or name matches), champions (`elite===1`, ~7% + tier/danger), war-chiefs (name match /war.?chief|chieftain/, 35%); `orbs.dungeonReward(st, team, dungeon)` (called by dungeons.js clearDungeon: orbs by tier, books, potions), `orbs.poiReward(st, team, kind, x, z, tier)` (hoard, cursed, shrine, library, witch; called from pois.js). Quests/Warlord: other lanes just call `orbs.give`.
- **Spending**: cmd `{t:'orbspend', what, arg}`: `skillup` (arg = slot 0-3, a skill id, or `'ult'`; ranks 1-3 cost 1/2/3 orbs; equipped skills only), `reroll` (current perk/skill card; 1 orb, once per card), `revive` (instant respawn while dead, 1 orb), `relic` (arg = slot or auto weakest slot; 3 orbs; best-of-12 rare+ item equipped; only near a waystone or non-fallen town). Skill ranks: `team.sk.rank[skillId]` 0-3; `perks.applyRank` is applied inside `modSkill` (+12% damage, -6% cooldown per rank, rank 3 +10% size, +15% duration); the same applies to the ultimate (`orbs.ultOf`). Events `skillRank`, `orbRevive`, `relic`. Helpers `orbs.rankOf/rankCost/canRelic`, `perks.rerollCard(st, team)` / `perks.reroll(st, teamId)` (hidden shrine POI uses it).
- **Ultimates (R)**: skills with `ult:true` in SKILLS (12, `ULTS`): quake, rain, nova, keg, judge (the four background defaults + one for every old lord theme), meteors (rain of fire), bladestorm, soulstorm (storm pulses), deadmarch, warband, cutthroats, zealhost (summon hordes). `team.sk.ult` = equipped id, `team.sk.ults` = known ults. sim.js uses `ultOf(team) || f.charge` for the charge and `castUlt` for `kind` rain/storm/horde (blast kind uses the old castCharge). Cmd `{t:'setult', id}`. `{t:'equipskill', id, slot}` equips a known normal skill anywhere (no stronghold needed in v4).
- **Books**: item `{kind:'book', slot:'book', skill, name, rarity, tier, price, icon, ult, uid}`; every SKILLS entry has `book:{tier 1..3}`. loot.js exports `makeBook(skillId)`, `rollBook(rng, tier 1..4, {known:[ids], ult:bool})` (TOWNS: use it or `orbs.shopBook(st, teamId, tier)` for trainers/merchants; price = `BOOK.price[tier]`), `bookPrice`. Ground books are `st.items` entries with `kind:'book'` and go to the backpack `team.bag` via the `pickup` hook (before gear.js). Cmd `{t:'usebook', item: uid}` teaches the skill (auto-equips into a free slot; an ultimate book makes it your R). Duplicates: tier 1-2 give half price in gold, tier 3 gives 1 orb. `{t:'sellbag', item}` sells a book (40% of price). Book drop chances in `BOOK.chance` (boss 45%, chests 10% + danger, dungeon 2 books).
- **Potions**: reuses gear.js `team.pots {heal, surge}` and `gear` op `potion` (Q); ECON adds drops (`POTION_DROP`) straight into the pouch (`orbs.giveHealPotion`), chests, bosses, dungeons. AI heroes drink at 38% HP.
- **Death economy**: on every hero death (`orbs.onKill` hook, also exported `orbs.onHeroDeath(st, team)`, idempotent per step) 30% of carried gold goes into `st.drops[] = {id, x, z, gold, team (owner), t, exp}` (max 16). Any living hero within 2.6 m takes it (rivals too), or cmd `{t:'pickupdrop', id}` within 6 m; expires after 300 s. Events `drop`, `dropPick`, `dropGone` (UI/render: draw a gold pile at x,z). CORE's respawn flow is untouched.
- **Gold scarcity**: `team.income` forced to `ECON4.stipend` (0) each step by `orbs.update`; monster `goldV` x0.45 once at death (orbs.onKill runs before the sim reads it); chest gold x0.6. `perks.dangerAt` now measures distance from the capital / toward the orc war-camp (towns are low danger) when no hearts exist, which scales loot tiers and book/potion odds.
- **HUD**: `orbs.economySummary(st, teamId)` -> `{gold, orbs, orbsTotal, income, slots:[{slot,id,name,icon,rank,maxRank,upCost,canUp}], ult:{id,name,icon,rank,maxRank,upCost,canUp,cd,known}, pots:{heal,surge,cd}, bag:[books], bagMax, costs, canReroll, canRevive, canRelic, drops:[...]}`.
- **AI heroes (teams 1-3)**: `orbs.update` makes them read books, spend orbs on their lowest-ranked skill, buy relics with spare orbs, orb-revive; disable per team with `team.econAuto = false`.
- Tests: `node tools/v4-econ-test.js` (orbs, ranks, books, drops, revive, reroll, relic, all 55 skills and 4 ult kinds), `node tools/skillcheck.js` (rewritten for backgrounds).

- **Entry points** (same signatures main.js already uses): `createAI(st, teamId, skill?)` where skill = `'easy'|'normal'|'hard'` or 0/1/2 (default `st.aiDiff`, else normal); `aiInput(st, ai, dt)` returns the human input struct `{mx,mz,aimX,aimZ,atk,casts,hold,charge,cmds}`; `rivalReport(st)` returns `[{team,bg,lvl,xp,hp,maxHp,alive,gold,orbs,followers,kills,score,deaths,mode,goal,x,z,levelT[],idleMax,stat,quests,dungeons}]`; `aiOf(st, teamId)` gives the AI state of a team. Teams 1-3 are rivals; team 0 only when `auto=1`/headless. No Math.random: each AI has a seeded `ai.rng` (deterministic per seed).
- **Brain** (decides every `P.think` s, staggered by a seeded jitter; per-step part only does aim/dodge/skills): sense (limited sight `P.sight`, stealth respected, nothing inside standing towns) -> fight ratio (time-to-die / time-to-kill including followers) -> flee (towards a town/waystone away from the threat centroid, waystone jump when far, else run away) / fight / goal. Goals are picked by utility = value / (walk + work), gated by a fight-ratio safety check that grows after failures: `camp`, `dungeon` (estimates unspawned dungeons from `DUNGEON`), `poi`, `chest`, `item`, `drop` (death piles), `shrine`, `hunt` (a rival seen within 28 s, from `ai.mem.heroes`, only after minute 4 and never inside a safe zone), `town` (turn in bounties, accept up to 3 easy bounties, buy potions via `{t:'gear',op:'buypot'}`, gear upgrades, skill books, a mercenary via `recruit`, trainer skills), `defend` (besieged town), `warcamp` (orc banner), `warlord` (min 16+, lvl 9+, power >= 14), `rest`, `explore`. Knowledge: hero only knows explored 16 m cells + towns + discovered waystones/POIs/dungeons (`ai.mem.ex`).
- **Combat**: aimed skills with target lead, groups for AoE, hold-and-release skills (stands still while charging), kiting for ranged heroes, dodge skills / telegraph and projectile evasion (`dangerAt`: blast timers, ground zones, projectiles; reaction chance and delay by difficulty), charged spell on clusters/big targets, gives up on a target it cannot damage for 14 s.
- **Difficulty** (`DIFF` in ai_util.js): easy = slow decisions 0.5 s, aim error 0.2 rad, 30% dodge, no hunting, needs fight ratio 2.1; normal 0.36 s / 0.09 / 65% / 1.6; hard 0.24 s / 0.035 / 92% / 1.3 and 1.3x aggression.
- **Uses from other lanes (all defensive)**: sim `hostile, reviveCost`; towns `isSafeZone, townById, skillPrice, st.towns[].{state,services,stock,quests,tr}`; recruits `mercenaryOffers`; gear cmds `{t:'gear',op:'buypot'|'equip'}`; orbs.js already drinks potions, reads books and spends orbs for rivals (AI does not duplicate); horde `st.horde.{camps,warlord,ready}`; perks `modSkill`, `PERKS`; travel `st.waystones[].disc`, `{t:'tele',ws}`; pois `{t:'poi',id}`; `{t:'pickupdrop',id}`. Perk picks are weighted by `team.bg` affinities (`ai_items.js scorePerk`).
- Tools: `node tools/match.js <seed> <minutes> [easy|normal|hard] [--quiet] [--every=N]` (one row per minute: bg, level, gold, orbs, followers, kills, deaths, score, goal; town states `T[...]` (s safe, b besieged, f fallen), horde front distance; end line with deaths, levels, dungeons, idleMax); `node tools/v4-rivals-test.js [seed] [minutes] [diff]` (no exceptions, levels >= 3, idle <= 60 s, a dungeon cleared in >= 15 min runs, determinism).
