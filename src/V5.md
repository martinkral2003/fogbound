# FOGBOUND v0.5: simple, short, co-op vs demons, League-of-Legends feel (binding contract for all lanes)

Read CLAUDE.md "Design v0.5" (the agreed design) first. V4.md/V3.md document the code that exists today; v0.5 SIMPLIFIES and REFOCUSES it. When V5.md and V4.md disagree, V5.md wins.
One-line pitch: 15-20 min co-op ARPG: you + 3 allied AI heroes defend a compact map from demon waves pouring out of Demon Gates; close all gates or kill the Demon Lord; lose if the capital falls.

## Game model (what exists after v0.5)
- Teams: `st.teams[0..3]` = the four heroes, ALL ALLIED (team 0 = the human, or AI with `auto=1`; teams 1-3 = allied AI heroes). `hostile(a,b)` is false among 0..4; team 4 = HUMANITY (militia, guards, villagers); team -1 = demons and wild monsters. Heroes do not damage each other. Gold stays per team. `team.bg` = class id ('soldier'|'hunter'|'mage'|'outlaw'); the menu picks the class.
- `st.over = {winner, reason}`; reasons: `'gates'` (all Demon Gates closed or Demon Lord dead = victory for everyone), `'capital'` (capital fell = defeat). `endGame(st, winner, reason)` exists in sim.js. Remove the old reasons 'warlord'.
- `st.objective` = `{id, text, kind:'defend'|'gate'|'event'|'lord'|'waiting', n, need, x, z, t}` (text <= 6 words plus counter, e.g. "Defend Oakvale" with n/need). Set only through `setObjective(st, obj)` exported by horde.js (DEMONS lane). The HUD shows it always with an arrow to (x,z).
- Skill kit (SKILLS lane): `team.kit = {slots:[id|null,id|null,id|null,id|null], lv:{skillId:level 1..3}, path:{skillId: branchIndex|undefined}, offers:[[opt,opt,opt]], ver}`; slot index 0..3 = keys Q W E R; slot 3 (R) is the ultimate unlocked at hero level 5. Offer option = `{kind:'skill'|'level'|'path', skill:id, branch?:int, text}`. Command `{t:'pickperk', idx}` picks from `offers[0]` (kept name; the card UI reuses it). Level cap 10 (`MAX_HERO_LVL`). No books, trainers, skill ranks via orbs, perks list or rerolls.
- Gear (COMBAT lane): 4 slots weapon/helmet/armor/amulet, each item has ONE stat `{slot, stat:'dmg'|'hp'|'spd'|'cdr', val, tier:0..2}`, tier = colour (white/blue/gold). Auto-equip if val is higher for the same stat/slot or if the slot is empty. No affixes, no resistances, no damage-type system: everything is one damage type (keep `dtype` as a visual tag for projectile colours only; status effects only come from abilities as riders). Consumables: `team.pots` max 3 kinds: heal, speed, shield.
- Servants (SERVANTS lane): `kind:'unit'`, `recruit:true`, `team.followers` max 4; each has 1-2 spells; no levels/evolution/gear. Sources: cage prisoner (POI 'cage'), hire in a city (gold), hero summon ability (`SKILLS` entry type 'summon'). Towns also spawn free militia (team 4).
- Towns (`st.towns`, TOWNS code stays): services shrink to shop (potions) + mercenary hire + waystone; no board, no trainer, no quests. Town states safe/besieged/fallen/saved stay.
- Demons (DEMONS lane): `world.sites.demon = {gates:[{id,x,z,tier}], lord:{x,z}}` replaces `orc`; `st.horde` renamed in place (keep `st.horde` key to avoid churn): `{dist, speed, gates:[{id,x,z,hp,maxHp,closed,tier}], assaults, lord:{id,state}, capital:{state,t}}`. Demon roster in `MONSTERS` (replaces orcs): imp (swarm, 1-2 hits), hellhound (fast), brute (tough), warlock (ranged bolts/heal), hulk (siege, slow), the Demon Lord (boss). Gates are destructible structures that spawn waves until closed (killed).
